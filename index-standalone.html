elment.js is a dependency-free JavaScript framework. Every element is built in one function call and wired in the next — drop a single file in a <script> tag and go.

Download elment.js See it run
BUILD Button({ class: 'btn' }, 'Click me')
WIRE (handleClick)

First call builds the vnode. Second call attaches the event. That's the whole API.

let form = { name: '', role: 'engineer', subscribe: false };

function SignupForm() {
  return Form({},
    Input({ type: 'text', value: form.name })
      ({ oninput: e => { form.name = e.target.value; rerender(); } }),

    Select({ value: form.role },
      Option({ value: 'engineer' }, 'Engineer'),
      Option({ value: 'designer' }, 'Designer')
    )({ onchange: e => { form.role = e.target.value; rerender(); } }),

    Button({}, 'Submit')(handleSubmit)
  );
}

Render methods

Parts list

Control flow isn't a template directive here — it's a function, like everything else. Each one returns a vnode, a list of vnodes, or null, and drops straight into a children list.

PartSignatureDoes
If / Else If(cond, then, Else(else)) Conditional branch. Branches can be lazy functions.
For For(array, (item, i) => ...) Maps data to a list of vnodes.
Case Case(value, { key: branch, default }) Switch-style branching on a value.
While While(condFn, bodyFn) Builds a list by looping until a condition flips.
Fetch Fetch(key, loaderFn, renderFn) Async render method — shows a loading state, re-renders on resolve.
provide / use provide(key, val) / use(key) Register a shared helper once, pull it in anywhere.
