Browser · Express · Zero dependencies

Build it. Wire it.
Ship it.

elment is a dependency-free DSL with two targets. elment.js builds and wires elements in the browser from one <script> tag. elment-framework renders scoped, slot-based components to HTML strings on your Express server.

Browser: elment.js Server: Express See it run

WIRE(handleClick)
DEFINEviews/card.elc
RENDERres.render('card', props)

Browser: build the vnode, then attach the event. Server: define the component, then render it per request.

01 · Browser

elment.js

Every element is built in one function call and wired in the next. Drop a single file in a <script> tag and go. No bundler, no npm install.

let form = { name: '', role: 'engineer', subscribe: false };

function SignupForm() {
  return Form({},
    Input({ type: 'text', value: form.name })
      ({ oninput: e => { form.name = e.target.value; rerender(); } }),

    Select({ value: form.role },
      Option({ value: 'engineer' }, 'Engineer'),
      Option({ value: 'designer' }, 'Designer')
    )({ onchange: e => { form.role = e.target.value; rerender(); } }),

    Button({}, 'Submit')(handleSubmit)
  );
}

Render methods

Parts list

Control flow isn't a template directive here. It's a function, like everything else. Each one returns a vnode, a list of vnodes, or null, and drops straight into a children list.

PartSignatureDoes
If / ElseIf(cond, then, Else(else))Conditional branch. Branches can be lazy functions.
ForFor(array, (item, i) => ...)Maps data to a list of vnodes.
CaseCase(value, { key: branch, default })Switch-style branching on a value.
WhileWhile(condFn, bodyFn)Builds a list by looping until a condition flips.
FetchFetch(key, loaderFn, renderFn)Async render method. Shows a loading state, re-renders on resolve.
provide / useprovide(key, val) / use(key)Register a shared helper once, pull it in anywhere.

02 · Server

elment-framework

The same idea on the backend. Define scoped, slot-based components in .elc files and render them to HTML strings. Express-ready, no dependencies.

A COMPONENT · views/card.elc

const { Module, css, html, props, Slot, div, h1, p } = require('elment-framework')();

Module.componentName = 'Card';

css({
  .card: { border: '1px solid #e6e6e6', borderRadius: '8px', padding: '16px' },
  .title: { fontSize: '20px', margin: '0 0 8px' },
});

module.exports = html(
  div({ '.card': true },
    h1({ '.title': true }, props.title),
    Slot('body'),
  )(
    { if: props.title },
    Slot('body')(props.body),
  )
);

EXPRESS INTEGRATION

const express = require('express');
const elment  = require('elment-framework');
const { engine, middleware } = elment.createExpressAdapter();

const app = express();
app.engine('elc', engine);
app.set('views', './views');
app.set('view engine', 'elc');
app.use(middleware);

// As a view file:
app.get('/', (req, res) => res.render('card', { title: 'Hi', body: '...' }));

// Ad-hoc:
app.get('/note', async (req, res) => {
  await res.renderComponent(Card, { title: 'Hi' });
});

// Full HTML document:
app.get('/page', async (req, res) => {
  await res.renderPage(Card, { title: 'Hi' }, { title: 'My page' });
});

DSL essentials

  • Conditions, then slotsSecond-call directives read as a sequence: div(...)( { if: a }, { if: b }, Slot('x')(...) ). Multiple { if } AND together.
  • SlotSlot('name') marks an injection point; Slot('name')(children) fills it. Components accept a second call too: Tabs(props)( Slot('a')(...) ).
  • Late-bound propsprops.title resolves per render. Use eq/ne for comparisons, since raw === against the proxy evaluates eagerly.
  • Lazy control flowIf / Else / For / While / Case go lazy on prop refs.
  • Scoped CSS.card becomes .iC1-card per render. In .elc files the quotes come off: .card:, #id:, extendClass(base, child):, font-size:.
  • SCSScss() takes SCSS text ($vars, nesting, &, @extend) or an object, which also supports nesting.
